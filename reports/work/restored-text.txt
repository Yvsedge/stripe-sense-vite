1. Introduction 
1.1 Background 
Urine reagent strips contain pads that change colour. Organising strip photographs with 
patient details and reference comparisons makes records easier to retrieve and review. 
 
StripeSense is a MERN laboratory project that combines a React interface, Express APIs and 
MongoDB storage. It compares photographed pad colours with a supplied reference profile 
without a trained machine-learning model. Results are unvalidated colour estimates; users 
must always consult a doctor. 
1.2 Problem Statement 
Doctors and individuals need to keep strip photographs and results linked to the correct 
patient. Separate images and notes make retrieval difficult. StripeSense provides private 
patient records and saved reports in one web application. 
1.3 Proposed Solution 
Users sign in, add a patient, upload a ten-pad strip photograph and reference profile, select 
the pad row and submit it. Axios sends the request to Express. The backend compares colours 
and saves the image and result in MongoDB for later viewing and printing. 
1.4 Objectives and Scope 
• Provide registration, sign in, persistent sessions and sign out. 
• Create patient records and associate each test with its patient and account owner. 
• Process a ten-pad image using a supplied colour-reference profile. 
• Save and retrieve reports, source images and analysis metadata in MongoDB. 
• Demonstrate API integration, input validation, account isolation and automated testing. 
Included: authentication, patient creation, colour matching, history, reports, deletion and dark 
mode. Hardware, trained ML, clinical validation, record editing and public deployment are 
outside the current scope.

4.2 Frontend Implementation 
React components manage forms and loading states using hooks. React Router separates 
public and protected pages. AuthProvider loads the session; RequireAuth redirects signed-out 
users. Axios sends JSON and multipart requests through /api. ThemeProvider remembers 
light/dark mode. 
4.3 Backend and API Implementation 
Express validates requests and handles uploads through Multer. Sharp decodes images, 
samples ten crop regions and compares CIELAB colours using Delta E. Salted scrypt hashes 
protect passwords. HttpOnly session cookies and ownerId checks restrict access to private 
records.

The native MongoDB driver stores users, sessions, patients and tests. insertOne creates 
records; find/findOne retrieves owned data; deleteOne removes an owned test. Images are 
embedded in test documents. Patient/test updates are not implemented. 
4.5 Validation and Error Handling 
Missing patient names and invalid crops/profiles are rejected. Duplicate patient codes return 
409. Unsupported uploads produce validation errors. Signed-out API requests return 401; 
other-account reports return 404. The interface displays connection failures and flags near-
tied colour matches for review.

8. CONCLUSION AND FUTURE SCOPE 
8.1 Conclusion 
StripeSense integrates React, Axios, Express and MongoDB to manage private patient 
records and photograph-based colour comparisons. Users can save, retrieve, print and delete 
reports. Automated tests verify the implemented workflow and account isolation. 
 
The project meets its MERN integration objective. Colour estimates are not validated medical 
measurements and cannot determine whether a result is clinically critical. Users must always 
consult a doctor. 
8.2 Future Scope 
Add patient/test editing, password reset, email verification, pagination and secure public 
deployment. Future analysis work could support manufacturer-specific reference charts and 
varied strip layouts, followed by independent validation before medical use.
